# Original game artwork

Release 0.16 adds [`public/art/duskwood-sprites.png`](../public/art/duskwood-sprites.png) and a vector lantern-road scene. [Duskwood art notes](ART-0.16.md) record the built-in tool, exact final prompt, saved source, alpha inspection and measured sprite crops.

Created with the built-in image generation tool on October 2–4, 2026. Images are original generated illustrations rather than extracted game assets. All nine raster atlases/illustrations are included locally, so the game has no image-generation or external image-service dependency at runtime.

- `public/art/elwynn.png`: original painterly forest background.
- `public/art/heroes.png`: original nine-character portrait atlas, read by CSS in a three-by-three grid.
- `public/art/world-sprites.png`: transparent environment and creature atlas used by the Canvas renderer.
- `public/art/hero-sprites.png`: transparent nine-class full-body sprite atlas used by the Canvas renderer.
- `public/art/companions.png`: transparent wolf, imp, Bear Form and fire totem atlas used by the Canvas renderer.
- `public/art/travel-sprites.png`: transparent horse, ram, wolf, saber, skeletal horse, two class steeds and two travel forms, used by the stable and Canvas renderer.
- `public/art/ragefire-sprites.png`: transparent volcanic creature and guardian atlas.
- `public/art/shadowfang-sprites.png`: transparent haunted castle creature and guardian atlas.
